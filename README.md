# Java de A à Z — Parc informatique (L3 Génie informatique, Maintenance)

Site de cours interactif (8 séances) pour apprendre Java à travers un projet de gestion de parc informatique.

## Utilisation
Ouvrir `index.html` dans un navigateur. Aucun serveur ni installation requis.

## Structure
- `index.html` : page principale
- `js/` : application (`app.js`), mini-interpréteur Java (`javamini.js`), données des séances (`data/s1.js` … `s8.js`)
- `media/` : vidéos des séances
